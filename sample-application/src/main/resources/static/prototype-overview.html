What the prototype includes

Operational intelligence

  • Health-state detection using Spring Boot actuator and custom self-healing monitoring
  • Incident creation and lifecycle tracking for degraded services
  • Deduplication to avoid duplicate incident work across the same component and failure type
  • Recovery orchestration with strategy-based automatic remediation

Engineering workflows

  • CPU, memory, dependency, and latency simulation scenarios
  • Live operational dashboard with summary metrics and active incident cards
  • Incident detail and recovery history for operational review
  • Micrometer and Prometheus-ready observability signals
